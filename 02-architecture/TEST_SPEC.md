## Functional Requirement Test Cases

Column conventions used by every FR section below:

* **Inputs** — concrete declared values in TRUE form (`key="value"`,
  semicolon-separated). Every value is a **string literal** as far as the P2
  self-consistency engine is concerned; predicates therefore compare against
  quoted forms (`expected_exit == "2"`, not `== 2`).
* **`state_mode`** — `shared | isolate_per_case | isolate_per_test`, declared on
  every case that touches `tasks.json` / `breaker.json` / `cache.json` /
  `audit.jsonl`. `isolate_per_test` obliges P3 to use **function-scoped**
  fixtures (never module-scope).
* **`subprocess_mode` / `shared_TASKQ_HOME`** — declared on every case that
  spawns a child process. `out_of_process` obliges P3 to propagate `PYTHONPATH`
  into the child env (pytest's `pythonpath` config does **not** inherit).
